# Publish the project website with GitHub Pages

1. Create a public GitHub repository named `stewart-platform-stabilization`.
2. Upload the files in this starter ZIP to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/website`, then click **Save**.
6. GitHub will show the published site URL after deployment. It usually looks like:
   `https://YOUR-USERNAME.github.io/stewart-platform-stabilization/`

Replace `YOUR-USERNAME` with your actual GitHub username. The URL will only work after the repository and Pages deployment are set up.
